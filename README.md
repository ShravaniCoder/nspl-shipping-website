# NSPL Shipping Landing Page

React + Vite + Tailwind CSS landing page for Naventra Shipping India Pvt Ltd.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
